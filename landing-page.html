How it works

From idea to delivered artifact in a structured, repeatable process.

Describe

Tell Claude what you want to build. A landing page, a slide deck, a set of social media posts.

Plan

Claude asks clarifying questions, routes to the right references, and presents an execution plan.

Build

HTML is generated step by step with per-section previews. You approve each stage before continuing.

Verify

Structural, visual, and design quality checks run automatically before delivery.
